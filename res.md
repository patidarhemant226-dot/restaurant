27. SECURITY

Keep the implementation secure.

Rules:

Never expose secret keys in client components.
Keep sensitive environment variables server-side.
Never hardcode API secrets.
Validate form input.
Sanitize user-controlled data.
Avoid unsafe HTML injection.
Avoid unnecessary third-party scripts.
Use secure server-side handling for reservation/contact forms.
Keep dependencies updated.
Follow Next.js security best practices.
Do not expose internal server information in production errors.

If reservation functionality is implemented, use server-side validation and safe request handling.
